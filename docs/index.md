## 这是什么？

一份**面向完全零基础用户**的科学上网教程。不预设任何背景知识，从「为什么要用」讲到「怎么配置」再到「出问题了怎么办」。

## 适合谁？

- 🎓 想访问海外学术资源的学生 / 研究者
- 💻 程序员、运维、独立开发者
- 🌐 需要使用部分海外服务的普通用户
- 🔒 注重公共网络下隐私保护的人

## 阅读顺序建议

按章节顺序阅读，每章都建立在前一章的基础上：

1. [为什么需要科学上网](/01-why) — 先理解动机和风险
2. [基础概念](/02-concepts) — 搞懂代理、节点、订阅、机场
3. [客户端选择](/03-clients) — 选一个适合你的客户端
4. [机场推荐](/04-airports) — 选一个靠谱的服务商
5. [Windows 操作](/05-windows) / [手机配置](/06-mobile) — 动手配置
6. [聚合 App 与机场的差异](/07-comparison) — 了解两种方案的取舍

> ⚠️ **法律与风险提示**：不同地区对网络访问工具的规定不同。使用前请了解并遵守你所在地区的法律法规。详见 [安全与免责](/09-safety)。
