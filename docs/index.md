## 🚀 快速开始

已经等不及了？三步直接上手：

1. 去 [04 机场推荐](04-airports.md) 选一个机场，购买并拿到订阅链接
2. 按 [05 Windows 操作](05-windows.md) 或 [06 手机配置](06-mobile.md) 装好客户端
3. 遇到问题先查 [08 常见问题](08-faq.md)

> ⚠️ **法律与风险提示**：不同地区对网络访问工具的规定不同。使用前请了解并遵守你所在地区的法律法规。详见 [安全与免责](09-safety.md)。
