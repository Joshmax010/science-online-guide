# 原始资料档案（只读）

本目录用于换设备后找回作者原稿，不作为 VitePress 网站的输入；网站正文以 `docs/` 为准。

## 保存内容

- `科学上网完全指南.docx`：作者提供的 DOCX，按原字节保存，含 13 张原图。
- `科学上网完全指南.md`：作者另行提供的原版 Markdown，按原字节保存。
- `图片和附件/`：13 张未压缩为 WebP 的 PNG/JPG 原图，保留 Markdown 引用的原文件名和目录结构。
- `manifest.json`：15 个原始文件的相对路径、字节数与 SHA-256；每张图附 DOCX 内嵌媒体对应关系。

原图文件夹在迁移准备时已不在原位置，因此从 Git 历史提交 `38d9f71` 恢复图片。全部 13 张恢复图片的 SHA-256 与 DOCX 内嵌图像一致，不是从 WebP 反向转换或重新压缩的结果。

两份原稿可能存在文字/导出差异，不应将其当成完全相同的版本。原始 Markdown 中的空链接、转义字符、带空格的图路径属于原稿的一部分，归档未擅自修复；网站阅读版本已另行处理。

## 校验

安装 Node.js 后，在项目根目录运行：

```bash
npm run verify:originals
```

正确结果是 15 个文件通过 SHA-256 和字节数校验。校验失败时先找回原件，不要用当前网站文件覆盖归档来消除错误。

本目录与原始图片仅备份项目内容，不包含 GitHub/Cloudflare 密钥、Hermes 配置或聊天记录。设备来源路径不写入清单。原稿正文与 DOCX 元数据已经检查，未发现设备绝对路径或常见凭证模式；截图做过人工目视检查，但不构成对所有细小文字的完全安全保证。
